# Maintainers

| Handle | Role | Areas |
|---|---|---|
| `@sedam-or` | lead maintainer, repository administrator | all |
| _vacant_ (`M-BUS`) | backup maintainer, named by the lead before v1.0 | all |

Ownership of paths for review is in [`.github/CODEOWNERS`](.github/CODEOWNERS).

## Contact channels

| Purpose | Channel |
|---|---|
| Security reports | GitHub private vulnerability reporting (see [`SECURITY.md`](SECURITY.md)) |
| Conduct reports | a private GitHub security advisory whose title starts with `[CoC]` (see [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md)), until a dedicated conduct address is set up (`M-CONTACT`) |
| Everything else | GitHub issues and discussions |

No personal email address is published in this repository. A channel is added here only when
it can be reached without exposing a maintainer's private contact details.

## Changing this file

Adding or removing a maintainer requires the approval of all existing maintainers and a
decision entry in `spec/decisions.md`.
