**not** grant any right to the names or logos used by the project, including the name
"Nivaras" and the project logo.

## Permitted without asking

- Stating that your software works with, is built on, or is compatible with Nivaras.
- Linking to the project, and writing factual references in articles, reviews and talks.
- Redistributing unmodified official builds with the names and logos intact.

## Requires written permission from the maintainers

- Using the name or logo for a product, service, domain, company or social account.
- Using them in a way that suggests endorsement by, or affiliation with, the project.

A modified version must use a different name and logo. The code licence is not affected.
