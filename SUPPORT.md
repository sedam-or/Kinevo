# Support

## Where to ask

| Need | Go to |
|---|---|
| A bug, with steps to reproduce | a GitHub issue, using the bug template |
| A question about use or setup | GitHub discussions |
| A feature or behaviour change | an issue labelled `rfc` (GOVERNANCE.md §3) |
| A security problem | private report only (SECURITY.md) |
| Conduct | see CODE_OF_CONDUCT.md |

## What to expect

- Community support is best-effort. Maintainers answer when they can; no response-time
  guarantee is given for community questions.
- Security reports have the response targets in SECURITY.md.
- Hosted-cloud customers will have a support channel and service levels defined in
  `spec/15-cloud.md` and the operations targets in `spec/11-operations.md`, once the cloud
  launches. Those values are drafts until the maintainer publishes them.

## Supported versions

Before 1.0, only the latest release gets fixes. From 1.0 onward, see RELEASING.md §4.

## Self-hosting

Self-hosted instances are operated by their owner. The project provides backup and restore
guidance and the upgrade notes in each release; it does not operate your instance.
