# 06 — Domain model and database

Depends on: `02-architecture.md`, `03-module-system.md`, `04-policies.md`. Requirement prefix: `DOM`.
This is the schema of record. A migration task must implement it exactly; a change to a table is a
change to this file first (rule M). SQL is PostgreSQL 17 dialect. Each table is owned by one module;
only that module's repositories touch it (CA-04).

## 1. Conventions

| ID | Convention |
|---|---|
| DOM-01 | Primary keys are `uuid` (UUIDv7, generated by the application). No serial keys except `outbox_events.seq`. |
| DOM-02 | Enumerations are `text` with a named `CHECK` constraint (not PostgreSQL enum types), so adding a value is a plain migration. |
| DOM-03 | Instants are `timestamptz` (UTC). Calendar dates that mean "a day in the account's timezone" are `date`. Ranges are half-open `[start, end)`. |
| DOM-04 | Every tenant table has `account_id uuid not null references accounts(id) on delete cascade`, RLS **enabled and forced**, and policy `tenant_isolation` (§2). Deleting an account cascades to all its data. |
| DOM-05 | Mutable aggregates have `version bigint not null default 1` incremented by the repository on every update; updates use `WHERE id=$1 AND version=$2` and report `0 rows` as `version_conflict`. |
| DOM-06 | Every table has `created_at timestamptz not null default now()`; mutable ones also `updated_at`. (`default now()` is a database safety net; the application sets values from its injected clock.) |
| DOM-07 | Text identity: emails are stored lower-cased and Unicode NFC-normalised (`citext` column). User-visible text is stored as written, trimmed, NFC-normalised (`standards/validation.md`). |
| DOM-08 | Money: `bigint` minor units + `char(3)` ISO-4217. Percent: basis points `int`. No floating-point columns anywhere. |
| DOM-09 | JSON columns (`jsonb`) are used only for: policy values, AI proposal payloads, canvas scenes, Tiptap documents, outbox/job payloads, scheduler results/snapshots, audit details. Each has a versioned schema in `standards/contracts.md`. |
| DOM-10 | Secrets are never columns of plain text: they live in `secrets` as AEAD ciphertext (D-19) or as one-way hashes (passwords, tokens). |

## 2. Extensions, roles and RLS

```sql
-- migration 0001 (runs as kinevo_migrator)
CREATE EXTENSION IF NOT EXISTS citext;
CREATE EXTENSION IF NOT EXISTS btree_gist;   -- no-overlap constraint on assignments

-- roles (created by `kinevo migrate --bootstrap` or documented SQL; passwords from env, never in SQL files)
--   kinevo_migrator : owns all objects, NOSUPERUSER, NOBYPASSRLS
--   kinevo_app      : NOSUPERUSER NOBYPASSRLS NOCREATEDB NOCREATEROLE; DML on tables; no DDL
--   kinevo_system   : NOSUPERUSER NOBYPASSRLS; DML only on the tables listed in §2.2

-- helper applied to every tenant table T (generated in each module migration)
ALTER TABLE T ENABLE ROW LEVEL SECURITY;
ALTER TABLE T FORCE  ROW LEVEL SECURITY;
CREATE POLICY tenant_isolation ON T
  USING      (account_id = NULLIF(current_setting('app.account_id', true), '')::uuid)
  WITH CHECK (account_id = NULLIF(current_setting('app.account_id', true), '')::uuid);
```

- If `app.account_id` is unset, `NULLIF(...)` is `NULL`, the comparison is never true, and **no rows are visible or writable** (deny by default, SEC-05).
- `FORCE` makes RLS apply even to the table owner. The application never connects as the owner anyway (ARCH-21).
- Tests that assert isolation must run as `kinevo_app` (not as a superuser, who bypasses RLS).

### 2.1 Tables without a tenant column

`instance_settings`, `instance_modules`, `policy_versions` (instance rows), `invites`, `billing_webhook_events`, `jobs` (system jobs), `outbox_events` (system events), `schema_migrations`. They are reachable only through repositories that require the `instance_admin` permission or the system context, and carry their own grants.

### 2.2 System role (`kinevo_system`) grants

| Table | Privileges | Why |
|---|---|---|
| `accounts` | SELECT by email, INSERT, UPDATE of lockout/login columns | login lookup, registration, lockout |
| `refresh_tokens`, `refresh_token_families` | SELECT, UPDATE | rotation before the account is known |
| `jobs`, `outbox_events`, `outbox_deliveries` | SELECT, UPDATE | worker claim/dispatch across accounts |
| `instance_settings`, `instance_modules`, `policy_versions`, `invites`, `audit_log` | SELECT, INSERT (audit: insert only) | instance maintenance |
| every tenant table | **none** | the worker switches to the account's context (`Tx::begin(account_id)` as `kinevo_app`) for tenant work |

## 3. Instance and platform tables

```sql
CREATE TABLE instance_settings (
  id               smallint PRIMARY KEY CHECK (id = 1),
  setup_completed  boolean NOT NULL DEFAULT false,
  setup_token_hash bytea,
  base_url         text,
  default_locale   text NOT NULL DEFAULT 'en' CONSTRAINT instance_locale_ck CHECK (default_locale IN ('en','id')),
  template_id      text,
  created_at       timestamptz NOT NULL DEFAULT now(),
  updated_at       timestamptz NOT NULL DEFAULT now(),
  version          bigint NOT NULL DEFAULT 1
);

CREATE TABLE instance_modules (
  module_key  text PRIMARY KEY CHECK (module_key ~ '^[a-z][a-z0-9_]{1,23}$'),
  enabled     boolean NOT NULL,
  updated_at  timestamptz NOT NULL DEFAULT now(),
  updated_by  uuid REFERENCES accounts(id) ON DELETE SET NULL,
  version     bigint NOT NULL DEFAULT 1
);

CREATE TABLE policy_versions (
  id             uuid PRIMARY KEY,
  scope          text NOT NULL CONSTRAINT policy_scope_ck CHECK (scope IN ('instance','account')),
  account_id     uuid REFERENCES accounts(id) ON DELETE CASCADE,
  key            text NOT NULL CHECK (key ~ '^[a-z][a-z0-9_]*(\.[a-z][a-z0-9_]*)+$'),
  value          jsonb NOT NULL,
  effective_from timestamptz NOT NULL,
  created_by     uuid REFERENCES accounts(id) ON DELETE SET NULL,
  created_at     timestamptz NOT NULL DEFAULT now(),
  CONSTRAINT policy_scope_account_ck CHECK ((scope = 'instance') = (account_id IS NULL))
);
CREATE INDEX policy_versions_lookup ON policy_versions (key, scope, account_id, effective_from DESC, id DESC);
-- RLS: instance rows readable by all accounts (non-secret); account rows only by their account.
--   USING (account_id IS NULL OR account_id = <current>) ; WITH CHECK (account_id = <current>)  [instance writes via kinevo_system]

CREATE TABLE secrets (
  id          uuid PRIMARY KEY,
  account_id  uuid REFERENCES accounts(id) ON DELETE CASCADE,   -- null = instance secret
  name        text NOT NULL,                                     -- e.g. 'ai.api_key', 'billing.gateway_key', 'smtp.password'
  ciphertext  bytea NOT NULL,
  nonce       bytea NOT NULL,
  key_id      smallint NOT NULL,                                 -- which master key encrypted it
  last4       text,                                              -- display mask only
  created_at  timestamptz NOT NULL DEFAULT now(),
  updated_at  timestamptz NOT NULL DEFAULT now(),
  UNIQUE NULLS NOT DISTINCT (account_id, name)
);

CREATE TABLE audit_log (
  id            uuid PRIMARY KEY,
  account_id    uuid REFERENCES accounts(id) ON DELETE CASCADE,  -- subject account; null = instance event
  actor_id      uuid,                                            -- who did it (no FK: survives deletion)
  action        text NOT NULL,                                   -- e.g. 'auth.login_failed', 'module.switched'
  target_type   text,
  target_id     text,
  details       jsonb NOT NULL DEFAULT '{}'::jsonb,              -- NEVER PII/content/secrets (SEC-04)
  request_id    text,
  occurred_at   timestamptz NOT NULL
);
CREATE INDEX audit_log_by_account ON audit_log (account_id, occurred_at DESC);
-- Append-only: kinevo_app has INSERT and SELECT only; a trigger raises on UPDATE/DELETE for all roles except the retention job's SECURITY DEFINER function.

CREATE TABLE outbox_events (
  seq         bigserial PRIMARY KEY,
  id          uuid NOT NULL UNIQUE,
  account_id  uuid REFERENCES accounts(id) ON DELETE CASCADE,
  kind        text NOT NULL,
  payload     jsonb NOT NULL,                                    -- ids and enums only; no content
  created_at  timestamptz NOT NULL
);
CREATE TABLE outbox_deliveries (
  event_id        uuid NOT NULL REFERENCES outbox_events(id) ON DELETE CASCADE,
  subscriber      text NOT NULL,
  state           text NOT NULL DEFAULT 'pending' CONSTRAINT outbox_state_ck CHECK (state IN ('pending','delivered','dead')),
  attempts        int  NOT NULL DEFAULT 0,
  next_attempt_at timestamptz NOT NULL,
  last_error_code text,
  delivered_at    timestamptz,
  PRIMARY KEY (event_id, subscriber)
);
CREATE INDEX outbox_deliveries_due ON outbox_deliveries (next_attempt_at) WHERE state = 'pending';

CREATE TABLE jobs (
  id              uuid PRIMARY KEY,
  account_id      uuid REFERENCES accounts(id) ON DELETE CASCADE,
  kind            text NOT NULL,
  unique_key      text,                                          -- for recurring materialisation
  payload         jsonb NOT NULL DEFAULT '{}'::jsonb,
  state           text NOT NULL DEFAULT 'queued' CONSTRAINT job_state_ck CHECK (state IN ('queued','running','succeeded','failed','dead')),
  run_at          timestamptz NOT NULL,
  attempts        int NOT NULL DEFAULT 0,
  max_attempts    int NOT NULL,
  locked_by       text,
  locked_until    timestamptz,
  last_error_code text,
  created_at      timestamptz NOT NULL,
  finished_at     timestamptz,
  UNIQUE (kind, unique_key)
);
CREATE INDEX jobs_claim ON jobs (run_at, id) WHERE state = 'queued';

CREATE TABLE idempotency_keys (
  account_id    uuid NOT NULL REFERENCES accounts(id) ON DELETE CASCADE,
  key           text NOT NULL CHECK (char_length(key) BETWEEN 8 AND 128),
  method        text NOT NULL,
  path          text NOT NULL,
  request_hash  bytea NOT NULL,
  status_code   smallint,                                        -- null while in flight
  response_body bytea,
  created_at    timestamptz NOT NULL,
  expires_at    timestamptz NOT NULL,
  PRIMARY KEY (account_id, key)
);
```

## 4. Identity (`identity`, `admin`)

```sql
CREATE TABLE accounts (
  id                 uuid PRIMARY KEY,
  email              citext NOT NULL UNIQUE,
  email_verified_at  timestamptz,
  display_name       text NOT NULL CHECK (char_length(display_name) BETWEEN 1 AND 80),
  password_hash      text NOT NULL,                              -- argon2id PHC string
  locale             text NOT NULL DEFAULT 'en' CONSTRAINT account_locale_ck CHECK (locale IN ('en','id')),
  timezone           text NOT NULL,                              -- IANA name, validated by the application against the tz database
  week_start         smallint NOT NULL DEFAULT 1 CHECK (week_start BETWEEN 1 AND 7),  -- ISO weekday
  is_instance_admin  boolean NOT NULL DEFAULT false,
  status             text NOT NULL DEFAULT 'active' CONSTRAINT account_status_ck CHECK (status IN ('active','disabled','deleting')),
  totp_secret_id     uuid REFERENCES secrets(id) ON DELETE SET NULL,
  totp_enabled       boolean NOT NULL DEFAULT false,
  failed_login_count int NOT NULL DEFAULT 0,
  failed_window_start timestamptz,
  locked_until       timestamptz,
  created_at         timestamptz NOT NULL DEFAULT now(),
  updated_at         timestamptz NOT NULL DEFAULT now(),
  version            bigint NOT NULL DEFAULT 1
);
-- RLS on accounts: USING (id = <current account>). Login/registration use the system role.

CREATE TABLE refresh_token_families (
  id                   uuid PRIMARY KEY,
  account_id           uuid NOT NULL REFERENCES accounts(id) ON DELETE CASCADE,
  device_label         text,                                      -- user-agent family only, e.g. 'Firefox on Linux'
  created_at           timestamptz NOT NULL,
  last_used_at         timestamptz NOT NULL,
  absolute_expires_at  timestamptz NOT NULL,
  revoked_at           timestamptz,
  revoked_reason       text CONSTRAINT rtf_reason_ck CHECK (revoked_reason IN ('logout','reuse_detected','password_changed','admin','expired'))
);
CREATE TABLE refresh_tokens (
  id           uuid PRIMARY KEY,
  family_id    uuid NOT NULL REFERENCES refresh_token_families(id) ON DELETE CASCADE,
  account_id   uuid NOT NULL REFERENCES accounts(id) ON DELETE CASCADE,
  token_hash   bytea NOT NULL UNIQUE,                             -- SHA-256 of a 256-bit random token
  issued_at    timestamptz NOT NULL,
  idle_expires_at timestamptz NOT NULL,
  used_at      timestamptz,                                       -- set when rotated; presenting a used token = reuse
  replaced_by  uuid REFERENCES refresh_tokens(id)
);
CREATE INDEX refresh_tokens_family ON refresh_tokens (family_id);

CREATE TABLE recovery_codes (
  id uuid PRIMARY KEY, account_id uuid NOT NULL REFERENCES accounts(id) ON DELETE CASCADE,
  code_hash bytea NOT NULL, used_at timestamptz, created_at timestamptz NOT NULL
);
CREATE TABLE password_resets (
  id uuid PRIMARY KEY, account_id uuid NOT NULL REFERENCES accounts(id) ON DELETE CASCADE,
  token_hash bytea NOT NULL UNIQUE, expires_at timestamptz NOT NULL, used_at timestamptz,
  created_by uuid, created_at timestamptz NOT NULL
);
CREATE TABLE invites (                                          -- instance-level
  id uuid PRIMARY KEY, token_hash bytea NOT NULL UNIQUE, email citext,
  created_by uuid REFERENCES accounts(id) ON DELETE SET NULL,
  expires_at timestamptz NOT NULL, used_at timestamptz, created_at timestamptz NOT NULL
);
CREATE TABLE account_exports (
  id uuid PRIMARY KEY, account_id uuid NOT NULL REFERENCES accounts(id) ON DELETE CASCADE,
  state text NOT NULL CONSTRAINT export_state_ck CHECK (state IN ('queued','running','ready','failed','expired')),
  bytes bytea, size_bytes bigint, created_at timestamptz NOT NULL, expires_at timestamptz NOT NULL
);
```

## 5. Workspaces, goals, tasks

```sql
CREATE TABLE workspaces (
  id uuid PRIMARY KEY,
  account_id uuid NOT NULL REFERENCES accounts(id) ON DELETE CASCADE,
  name citext NOT NULL CHECK (char_length(name) BETWEEN 1 AND 80),
  color text CHECK (color IS NULL OR color IN ('slate','red','orange','amber','green','teal','blue','violet','pink')),
  position int NOT NULL DEFAULT 0,
  is_default boolean NOT NULL DEFAULT false,
  archived_at timestamptz,
  created_at timestamptz NOT NULL DEFAULT now(), updated_at timestamptz NOT NULL DEFAULT now(),
  version bigint NOT NULL DEFAULT 1
);
CREATE UNIQUE INDEX workspaces_one_default ON workspaces (account_id) WHERE is_default;
CREATE UNIQUE INDEX workspaces_name_active ON workspaces (account_id, name) WHERE archived_at IS NULL;

CREATE TABLE goals (
  id uuid PRIMARY KEY,
  account_id uuid NOT NULL REFERENCES accounts(id) ON DELETE CASCADE,
  workspace_id uuid NOT NULL,
  title text NOT NULL CHECK (char_length(title) BETWEEN 1 AND 500),
  description text NOT NULL DEFAULT '',
  status text NOT NULL DEFAULT 'active' CONSTRAINT goal_status_ck CHECK (status IN ('active','paused','achieved','abandoned')),
  target_date date,
  created_at timestamptz NOT NULL DEFAULT now(), updated_at timestamptz NOT NULL DEFAULT now(),
  version bigint NOT NULL DEFAULT 1,
  FOREIGN KEY (workspace_id) REFERENCES workspaces(id),
  UNIQUE (workspace_id, id)
);
CREATE INDEX goals_by_ws ON goals (account_id, workspace_id, status);

CREATE TABLE milestones (
  id uuid PRIMARY KEY,
  account_id uuid NOT NULL REFERENCES accounts(id) ON DELETE CASCADE,
  goal_id uuid NOT NULL REFERENCES goals(id) ON DELETE CASCADE,
  title text NOT NULL CHECK (char_length(title) BETWEEN 1 AND 500),
  description text NOT NULL DEFAULT '',
  status text NOT NULL DEFAULT 'open' CONSTRAINT milestone_status_ck CHECK (status IN ('open','done')),
  target_date date,
  position int NOT NULL DEFAULT 0,
  created_at timestamptz NOT NULL DEFAULT now(), updated_at timestamptz NOT NULL DEFAULT now(),
  version bigint NOT NULL DEFAULT 1,
  UNIQUE (goal_id, id)
);

CREATE TABLE tasks (
  id uuid PRIMARY KEY,
  account_id uuid NOT NULL REFERENCES accounts(id) ON DELETE CASCADE,
  workspace_id uuid NOT NULL REFERENCES workspaces(id),
  goal_id uuid,
  milestone_id uuid,
  title text NOT NULL CHECK (char_length(title) BETWEEN 1 AND 500),
  notes text NOT NULL DEFAULT '',
  status text NOT NULL DEFAULT 'backlog' CONSTRAINT task_status_ck CHECK (status IN
    ('backlog','scheduled','in_progress','partial','continued','completed','skipped','missed','conflict')),
  priority_tier smallint NOT NULL CHECK (priority_tier BETWEEN 1 AND 3),
  estimate_minutes int CHECK (estimate_minutes IS NULL OR estimate_minutes BETWEEN 1 AND 1440),
  due_at timestamptz,
  is_anchor boolean NOT NULL DEFAULT false,
  progress_pct smallint NOT NULL DEFAULT 0 CHECK (progress_pct BETWEEN 0 AND 100),
  completed_at timestamptz,
  created_at timestamptz NOT NULL DEFAULT now(), updated_at timestamptz NOT NULL DEFAULT now(),
  version bigint NOT NULL DEFAULT 1,
  CONSTRAINT task_milestone_needs_goal CHECK (milestone_id IS NULL OR goal_id IS NOT NULL),
  CONSTRAINT task_goal_same_workspace  FOREIGN KEY (workspace_id, goal_id)  REFERENCES goals (workspace_id, id),
  CONSTRAINT task_milestone_in_goal    FOREIGN KEY (goal_id, milestone_id)  REFERENCES milestones (goal_id, id),
  CONSTRAINT task_completed_at_ck CHECK ((status = 'completed') = (completed_at IS NOT NULL))
);
CREATE UNIQUE INDEX tasks_one_open_anchor ON tasks (account_id) WHERE is_anchor AND status NOT IN ('completed','skipped');
CREATE INDEX tasks_open ON tasks (account_id, status) WHERE status NOT IN ('completed','skipped');
CREATE INDEX tasks_by_goal ON tasks (account_id, goal_id);

CREATE TABLE subtasks (
  id uuid PRIMARY KEY,
  account_id uuid NOT NULL REFERENCES accounts(id) ON DELETE CASCADE,
  task_id uuid NOT NULL REFERENCES tasks(id) ON DELETE CASCADE,
  title text NOT NULL CHECK (char_length(title) BETWEEN 1 AND 500),
  completed boolean NOT NULL DEFAULT false,
  position int NOT NULL DEFAULT 0,
  created_at timestamptz NOT NULL DEFAULT now(), updated_at timestamptz NOT NULL DEFAULT now(),
  version bigint NOT NULL DEFAULT 1
);
```

Notes: a task whose `goal_id` is null is **unanchored** (PRD principle 1). `ON DELETE` for `tasks.goal_id` is `NO ACTION`: deleting a goal with tasks is refused by the use case (`goal_has_tasks`) unless the caller chooses "detach tasks" (sets `goal_id`/`milestone_id` to null in the same transaction).

## 6. Landscape and scheduling

```sql
CREATE TABLE import_batches (
  id uuid PRIMARY KEY, account_id uuid NOT NULL REFERENCES accounts(id) ON DELETE CASCADE,
  source text NOT NULL CHECK (source IN ('ics')), filename text, event_count int NOT NULL,
  created_at timestamptz NOT NULL
);

CREATE TABLE landscape_events (
  id uuid PRIMARY KEY,
  account_id uuid NOT NULL REFERENCES accounts(id) ON DELETE CASCADE,
  title text NOT NULL CHECK (char_length(title) BETWEEN 1 AND 200),
  kind text NOT NULL CONSTRAINT landscape_kind_ck CHECK (kind IN ('one_time','recurring')),
  start_at timestamptz NOT NULL,
  end_at timestamptz NOT NULL,
  timezone text NOT NULL,                       -- IANA zone in which recurrence wall-clock times are expanded
  rrule jsonb,                                  -- {freq:'DAILY'|'WEEKLY', interval>=1, by_day:[MO..SU], count?, until?, until_date_only}
  source text NOT NULL DEFAULT 'manual' CHECK (source IN ('manual','ics')),
  external_uid text,
  import_batch_id uuid REFERENCES import_batches(id) ON DELETE SET NULL,
  created_at timestamptz NOT NULL DEFAULT now(), updated_at timestamptz NOT NULL DEFAULT now(),
  version bigint NOT NULL DEFAULT 1,
  CHECK (end_at > start_at),
  CHECK ((kind = 'recurring') = (rrule IS NOT NULL))
);
CREATE UNIQUE INDEX landscape_ics_uid ON landscape_events (account_id, external_uid) WHERE external_uid IS NOT NULL;

CREATE TABLE schedule_overrides (
  id uuid PRIMARY KEY,
  account_id uuid NOT NULL REFERENCES accounts(id) ON DELETE CASCADE,
  event_id uuid NOT NULL REFERENCES landscape_events(id) ON DELETE CASCADE,
  kind text NOT NULL CONSTRAINT override_kind_ck CHECK (kind IN ('permanent','one_time')),
  effective_from date NOT NULL,
  effective_to date NOT NULL,
  override_start_at timestamptz NOT NULL,
  override_end_at timestamptz NOT NULL,
  cancels_occurrence boolean NOT NULL DEFAULT false,
  reason text,
  created_at timestamptz NOT NULL DEFAULT now(),
  CHECK (override_end_at > override_start_at), CHECK (effective_to >= effective_from)
);

CREATE TABLE schedule_states (                  -- one row per account
  account_id uuid PRIMARY KEY REFERENCES accounts(id) ON DELETE CASCADE,
  version bigint NOT NULL DEFAULT 0,            -- schedule version (optimistic base for drafts)
  review_state text NOT NULL DEFAULT 'clean' CHECK (review_state IN ('clean','needs_review')),
  review_reason text, updated_at timestamptz NOT NULL
);

CREATE TABLE schedule_assignments (
  id uuid PRIMARY KEY,
  account_id uuid NOT NULL REFERENCES accounts(id) ON DELETE CASCADE,
  task_id uuid NOT NULL REFERENCES tasks(id) ON DELETE CASCADE,
  start_at timestamptz NOT NULL, end_at timestamptz NOT NULL,
  source text NOT NULL CHECK (source IN ('auto','manual')),
  locked boolean NOT NULL DEFAULT false,
  state text NOT NULL DEFAULT 'current' CONSTRAINT assignment_state_ck CHECK (state IN ('current','superseded')),
  schedule_version bigint NOT NULL,
  superseded_at timestamptz, superseded_by_draft uuid,
  created_at timestamptz NOT NULL,
  CHECK (end_at > start_at),
  CONSTRAINT assignments_no_overlap EXCLUDE USING gist
    (account_id WITH =, tstzrange(start_at, end_at, '[)') WITH &&) WHERE (state = 'current')
);
CREATE UNIQUE INDEX assignments_one_current_per_task ON schedule_assignments (task_id) WHERE state = 'current';

CREATE TABLE schedule_drafts (
  id uuid PRIMARY KEY,
  account_id uuid NOT NULL REFERENCES accounts(id) ON DELETE CASCADE,
  kind text NOT NULL CHECK (kind IN ('weekly','manual','sync')),
  horizon_start timestamptz NOT NULL, horizon_end timestamptz NOT NULL,
  base_version bigint NOT NULL,
  status text NOT NULL DEFAULT 'pending' CONSTRAINT draft_status_ck CHECK (status IN ('pending','applied','dismissed','stale')),
  algorithm_version text NOT NULL,
  input_hash bytea NOT NULL,
  policy_snapshot jsonb NOT NULL,
  result jsonb NOT NULL,                         -- assignments, unassigned (+reason codes), moves, conflicts, explanations
  created_at timestamptz NOT NULL, decided_at timestamptz,
  CHECK (horizon_end > horizon_start)
);
CREATE UNIQUE INDEX drafts_one_pending_weekly ON schedule_drafts (account_id, horizon_start) WHERE kind = 'weekly' AND status = 'pending';

CREATE TABLE scheduler_runs (
  id uuid PRIMARY KEY,
  account_id uuid NOT NULL REFERENCES accounts(id) ON DELETE CASCADE,
  trigger text NOT NULL CHECK (trigger IN ('user','weekly','sync')),
  status text NOT NULL CHECK (status IN ('running','succeeded','failed')),
  lease_until timestamptz NOT NULL,
  draft_id uuid REFERENCES schedule_drafts(id) ON DELETE SET NULL,
  error_code text, started_at timestamptz NOT NULL, finished_at timestamptz
);
CREATE UNIQUE INDEX scheduler_one_running ON scheduler_runs (account_id) WHERE status = 'running';
```

The `assignments_no_overlap` exclusion constraint is the database-level guarantee behind rule SCH-R7 (`modules/scheduler.md`); it is **tested** by `TST` task "assignment overlap is rejected by the database" (a legacy doc claimed such a guarantee that the code did not provide; this spec requires a test, not just the DDL).

  base_url text NOT NULL, model text NOT NULL,

);
CREATE TABLE ai_proposals (

## 10. Entity relationships (conceptual)

```
account 1─* workspace 1─* goal 1─* milestone
              │            └──* task (goal? milestone?) 1─* subtask
              ├─* note ─* note_link ─▶ goal|milestone|task|canvas
              └─* canvas ─* canvas_link / canvas_file
account 1─* landscape_event 1─* schedule_override
account 1─1 schedule_state;  task 1─0..1 current schedule_assignment;  account 1─* schedule_draft / scheduler_run
task 1─* focus_session;  outbox_event ─▶ progress_event
account 1─* ai_proposal(goal) ; account 1─0..1 subscription 1─* invoice
```

## 11. Domain invariants (enforced in domain code **and**, where possible, by the database)

| ID | Invariant | Layers |
|---|---|---|
| DOM-20 | A task's milestone belongs to its goal; its goal belongs to its workspace. | domain + FK (§5) |
| DOM-21 | At most one non-terminal anchor task per account. | domain + partial unique index |
| DOM-22 | At most one *current* assignment per task; current assignments of an account never overlap in time. | scheduler domain + exclusion constraint |
| DOM-23 | At most one running focus session per account. | domain + partial unique index |
| DOM-24 | A task is `completed` iff `completed_at` is set; terminal statuses (`completed`, `skipped`) only transition to `backlog` (user reopen, D-36). | domain + CHECK |
| DOM-25 | Exactly one default workspace per account; it cannot be archived. | domain + partial unique index |
| DOM-26 | Policy versions and audit rows are never updated or deleted by application roles. | grants + trigger |
| DOM-27 | `landscape_events.kind='recurring'` iff `rrule` present; end after start. | domain + CHECK |
| DOM-28 | An account has at most one subscription row; invoices are immutable once `paid`. | domain + UNIQUE |

Per-module behaviour (state machines, validation, endpoints) is in `modules/*.md`.
