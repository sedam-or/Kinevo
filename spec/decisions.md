# Decision log

Status: **Accepted** unless marked otherwise. Each entry is binding on `spec/` and `tasks/`.
A decision changes only through a new entry that names the one it supersedes (or an ADR in
`spec/adr/`). Owner answers came from the Phase 0 decision round on 2026-10-25. "Architect"
means the owner's standing "decide for me" instruction was applied.

| ID | Decision | Source | Supersedes |
|---|---|---|---|
| D-01 | "Drag and drop the feature" means two things. (a) **Easy install**: one image, a setup wizard, safe defaults. (b) **First-party modules compiled into the binary, switched on/off per install** (wizard + admin settings), with no code edits. A third-party plugin API (e.g. WASM) is **deferred** to an RFC after 1.0. Literal drag-and-drop interaction is not required; module selection uses an accessible list of switches. | Owner ("Both"; Q1b "Toggle + RLS") | — |
| D-02 | The backend is **rebuilt in Rust** from this spec, not ported line by line. Stack: axum (tokio, tower, hyper), sqlx, **PostgreSQL only**. See ADR-0001. | Owner (Q2) | legacy ADR-001/007 runtime |
| D-03 | The product name stays **Kinevo**. The name-clearance checklist (domain, GitHub org, trademark classes 9/42, EN/ID pronunciation, connotations) is a maintainer action. | Owner (Q3) | — |
| D-04 | License: **AGPL-3.0-only** for the whole repository, effective from the first commit after `legacy-v0`. Contributions come in under the same license with **DCO sign-off** (no CLA). Revisit trigger: a concrete commercial-licensing request, which would require a CLA going forward. The `legacy-v0` tag stays MIT.
