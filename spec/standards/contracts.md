# Standard — Contracts and canonical forms (CON)

Every value that crosses a process, storage or time boundary has exactly one canonical form. `07-api-conventions.md`
states the HTTP rules; this file fixes the data shapes. OpenAPI is generated from code (API-06); JSON Schemas for the
`jsonb:<schema>` documents are committed under `contracts/` (created in M1) and referenced here by name.

## 1. Scalars

| Concept | Canonical form | Notes |
|---|---|---|
| Identifier | lower-case hyphenated UUID string (UUIDv7 generated by the server; clients may supply any valid UUID where documented) | never sequential; never reveals tenant |
| Instant | RFC 3339 UTC `YYYY-MM-DDTHH:MM:SS[.fff]Z` | input offsets accepted, output always `Z`, milliseconds only when non-zero |
| Date | `YYYY-MM-DD` | account-local calendar date |
| Local time | `HH:MM` | policy values only |
| Timezone | IANA name, e.g. `Asia/Jakarta` | validated against the embedded tzdb |
| Duration | integer with unit in the field name: `_minutes`, `_seconds` | never ISO-8601 durations |
| Percentage | integer basis points, field suffix `_bp` | 100 % = 10000 |
| Progress percent (task) | integer `0..100`, field `progress_pct` | derived, TASK-FR-05 |
| Money | `{"amount_minor": <int>, "currency": "<ISO-4217>"}` | `amount_minor` ≥ 0, ≤ 10^12 |
| Enum | lower snake_case string | extensible in responses |
| Boolean | JSON `true`/`false` | |
| Version | integer ≥ 1, field `version` | optimistic concurrency |
| Locale | `en` \| `id` | BCP 47 primary subtag only |
| Version of a document schema | field `schema`: `"<name>_v<n>"` | e.g. `ai_breakdown_v1` |

## 2. Collections and envelopes

| Concept | Shape |
|---|---|
| Page | `{ "items": [ … ], "next_cursor": string \| null }` |
| Problem | RFC 9457 object (API §3) |
| Validation error entry | `{ "path": "tasks[2].title", "code": "too_long", "details": { "max": 200 } }` — `path` uses dot/bracket notation of the **request** JSON |
| Allowed transitions | resources with a state machine expose `allowed_transitions: [ { "to": "completed", "requires": [] } ]` computed by the server for the caller (CA-15) |
| Error `details` | documented per code in `error-handling.md`; always JSON objects |
| Idempotency replay | same body/status as the original plus header `Idempotency-Replayed: true` |

## 3. Canonical JSON (for hashing and golden files)

Whenever bytes are hashed or compared (`payload_hash`, `input_hash`, golden fixtures), JSON is serialised by **RFC 8785 (JCS)**: UTF-8, no insignificant whitespace, object keys sorted by UTF-16 code units, numbers in shortest round-trip form (integers only in our schemas), strings with minimal escaping. The hash is SHA-256 over those bytes, lower-case hex.

## 4. Scheduler wire format

`scheduler_input_v1` (instants as RFC 3339 in the API; the pure crate converts to epoch seconds at its boundary):

```json
{
  "schema": "scheduler_input_v1",
  "horizon": { "start": "2026-11-02T00:00:00Z", "end": "2026-11-09T00:00:00Z" },
  "days": [ { "start": "2026-11-02T01:00:00Z", "end": "2026-11-02T15:00:00Z", "anchor_not_before": "2026-11-02T01:00:00Z" } ],
  "busy": [ { "start": "2026-11-02T02:00:00Z", "end": "2026-11-02T04:00:00Z" } ],
  "fixed": [ { "task_id": "0192…", "start": "2026-11-02T05:00:00Z", "end": "2026-11-02T05:25:00Z" } ],
  "tasks": [ {
      "task_id": "0192…", "duration_minutes": 45, "priority_tier": 2,
      "goal_deadline": null, "milestone_deadline": null, "task_deadline": "2026-11-05T10:00:00Z",
      "progress_pct": 0, "is_anchor": false, "current_slot": null } ],
  "params": { "min_slot_minutes": 15, "reserve_bp": 3000, "anchor_duration_minutes": 25, "daily_capacity_bp": null }
}
```

`scheduler_output_v1`:

```json
{
  "schema": "scheduler_output_v1", "algorithm_version": "sched-1",
  "assignments": [ { "task_id": "0192…", "start": "…", "end": "…",
                     "reasons": [ { "code": "RANK_PRIORITY", "params": { "tier": 2 } }, { "code": "FIRST_FITTING_SLOT", "params": { "day_index": 0 } } ] } ],
  "unassigned": [ { "task_id": "0192…", "code": "NO_AVAILABLE_SLOT", "violations": [ { "code": "DEADLINE_FEASIBILITY", "params": {} } ] } ],
  "moves": [ { "task_id": "0192…", "from": { "start": "…", "end": "…" }, "to": { "start": "…", "end": "…" } } ],
  "conflicts": [ "0192…" ]
}
```

Arrays are sorted as specified in `modules/scheduler.md` §2.2; the golden tests compare the JCS bytes.

## 5. Sync envelope

Defined in `modules/sync.md` §2 (`Op`, `Result`). Protocol version field `protocol_version: 1`. Canonical hash input for `payload_hash` = JCS of `{ "op_type", "entity_id", "base_version", "payload", "workspace_id" }` with absent optionals omitted.

## 6. Domain event envelope (outbox)

```json
{ "id": "uuid", "kind": "TaskCompleted", "v": 1, "account_id": "uuid", "occurred_at": "instant",
  "payload": { "task_id": "uuid", "workspace_id": "uuid", "goal_id": "uuid|null" } }
```
Payloads contain ids, enums and integers only (CA-11). A new field is additive; a breaking change bumps `v` and the dispatcher routes by `(kind, v)`.

## 8. Export format `export_v1` (ZIP)

```
kinevo-export-<account-uuid>-<YYYYMMDD>.zip
  README.txt                 # human explanation, format version, how to import ICS
  data.json                  # {schema:"export_v1", exported_at, account:{profile}, workspaces[], goals[], milestones[], tasks[], subtasks[],
                             #  landscape_events[], overrides[], assignments[], focus_sessions[], notes[], note_links[], canvases[], canvas_links[],
                             #  ai_proposals[](pending only), policies[](account scope)}
  landscape.ics              # RFC 5545
  canvas-files/<canvas-id>/<file_key>   # images > 1 MiB; smaller ones are base64 in data.json
```
Excluded: password hash, tokens, TOTP seed, recovery codes, API keys, audit log of other accounts, instance data. Ids are preserved; timestamps are canonical instants.

## 9. Files

| Kind | Canonical |
|---|---|
| ICS | UTF-8, CRLF, folded at 75 octets, `PRODID:-//Kinevo//<version>//EN` |
| Images (canvas) | stored as uploaded after validation; served with the stored MIME |
| ZIP (export) | deflate, UTF-8 names, no absolute paths, no `..` |

## 10. Compatibility rules (CON-C)

| ID | Rule |
|---|---|
| CON-C1 | Within `/api/v1`: adding optional request fields, response fields, endpoints, enum values (responses) and error codes is compatible; removing/renaming/retyping is breaking. |
| CON-C2 | `contracts/*.schema.json` changes are checked by a compatibility test against the previous released schema (`12-testing.md` TST-04). |
| CON-C3 | A schema version bump (`_v2`) requires a reader for `_v1` for at least one minor release. |
