# Kinevo — Marketing Site Specification (kinevo-site)

> STATUS: AUTHORITATIVE (P29, 2026-08-31). Canonical specification for the future
> public website. Documentation-only: NO implementation in P29. Visual language:
> **Kinevo Editorial Constructivism** (higher expression than the product's
> Tactile Editorial) — Swiss grid, axial/radial composition, constructivist
> typography, technical diagrams, paper texture, monochrome photography, progress
> arcs, timeline grids. Landing = **vertical scrolling manifesto**: each section
> is an independent editorial composition; the page must NOT become one giant
> magazine grid. Stitch source: `turn_intention_into_execution_1..11`,
> `marketing_hero`, `how_kinevo_works`, feature/campaign frames (classified
> MARKETING_ONLY in `stitch-convergence-matrix.md`). Every published claim passes
> `claims-registry.md`. Tagline (fixed): **"Kinevo — Turn intentions into execution."**

## 1. Site IA

1. **Hero** — "TURN INTENTIONS INTO EXECUTION." + the compact proposition
   ("workspace-scoped personal operating system…"). One primary CTA (Start Free)
   + secondary (GitHub).
2. **Problem** — "YOUR LIFE IS NOT A TODO LIST." / "TOO MANY THINGS. TOO MANY
   PLACES." Todo lists record wishes; calendars record events; neither respects
   reality.
3. **How it works** — the core loop: Intention → Structure → Schedule → Today →
   Execution → Progress → Review → Adapt (canonical diagram D01/D08).
4. **Goal / Intention** — "A GOAL SHOULD MOVE." AI breakdown: "AI proposes. You
   decide." (MK10 copy: transparent, editable, anchored).
5. **Hard Landscape / Reality** — "UPLOAD THE SCHEDULE. KEEP YOUR LIFE." /
   "LIFE CHANGED? CHANGE THE LANDSCAPE." KRS/ICS import, Permanent Shift,
   One-Time Exception; immutable blocks + freed capacity.
6. **Today / Execution** — "KNOW WHAT MATTERS NOW." / "YOU'VE GOT ENOUGH GOING
   ON. MAKE THE NEXT MOVE OBVIOUS." (MK11).
7. **Week** — "SEE THE WEEK BEFORE IT OWNS YOU." / "ZOOM OUT WITHOUT LOSING THE
   PLOT." Weekly draft review; Sync Now.
8. **Knowledge / Context** — "DON'T LET YOUR THINKING LIVE SOMEWHERE ELSE."
   Notes/Canvas/Links connected to execution.
9. **Progress / Review** — "SEE THE WORK BECOME PROGRESS." / "DON'T JUST DO MORE.
   UNDERSTAND WHAT HAPPENED." Progress events, honest analytics.
10. **Open source / Ownership** — "OWN THE SOFTWARE. OR LET KINEVO HOST IT FOR
    YOU." MIT Core, self-host, audit; "YOUR DATA ISN'T THE PRODUCT."
11. **Pricing** — Free / Pro / Power (launch hypotheses, marked as such);
    canonical copy "START FREE. BUILD YOUR SYSTEM." + "TRANSPARENT ALLOCATION."
    No SLA/SSO/storage/API-rate claims (prohibited — registry).
12. **Trust / Security** — architecture-honest statements only (registry §3
    SAFE list). No zero-knowledge/E2EE/compliance claims.
13. **CTA / Footer** — Start free · GitHub · Docs. "BUILT FOR PEOPLE WITH TOO
    MUCH GOING ON."

## 2. Component & composition rules

- Type: oversized constructivist display (marketing scale is free to exceed the
  product scale; product tokens do not bind marketing, family continuity
  encouraged); mono metadata kickers.
- Grid systems: axial center, radial focus (goal decomposition), Swiss columns,
  timeline grids — one dominant system per section, never all at once.
- Texture: warm-neutral paper grain; monochrome photography of serious
  individuals working (asset sets B/C/D — provenance required before use).
- Diagrams: canonical diagram set (D01–D08, dia_01–07) as the technical-visual
  backbone; regenerate at production resolution in P31+.
- Motion: scanning lines, reveal-on-scroll — reduced-motion respected; no
  three.js unless a later owner decision (Stitch experiment REJECT for now).
- Wrapped ("YOUR YEAR UNWRAPPED.") = campaign/annual concept — DEFERRED design
  direction (P32+ decision); not in launch site scope.

## 3. Non-goals

No CMS decision, no framework choice, no i18n implementation, no analytics
instrumentation (P32), no store-listing production (P36) — this file is the
specification those phases implement. The site never publishes pricing quotas,
AI-credit numbers, or compliance claims that the registry marks PROHIBITED.
