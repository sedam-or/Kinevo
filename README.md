# Nivaras

**Status: re-architecture in progress.** Nivaras is being rebuilt as an open-source,
self-hostable personal planning system (Rust backend, React PWA, Android app).
No runnable release exists on this branch yet.

- Why, and what was decided: [`spec/00-verdict.md`](spec/00-verdict.md), [`spec/decisions.md`](spec/decisions.md)
- The previous Laravel + Vue implementation: tag [`legacy-v0`](https://github.com/sedam-or/Kinevo/tree/legacy-v0) (MIT)
- Agent and contributor rules: [`AGENTS.md`](AGENTS.md), [`CLAUDE.md`](CLAUDE.md)
